# Error message localization

Configure the client with one of the built-in languages: English (`en`), Spanish (`es`), French (`fr`), German (`de`), Chinese (`zh`), or Japanese (`ja`). English is the default.

```ts
const client = new DorisioClient({
  baseUrl: 'https://api.dorisio.com',
  i18n: {
    language: 'es',
    translations: {
      es: {
        ERR_INVALID_AMOUNT: 'El importe personalizado no es válido.',
      },
    },
  },
});
```

Overrides are organized by language code, then error key. Omitted entries use the built-in translation for that language. `ERROR_TRANSLATIONS` exports the complete built-in catalogs, and `ErrorTranslationKey` exports the supported keys for typed overrides.

SDK errors include an `i18n` object with the selected `language` and stable `key`. `originalMessage` contains the message before localization.

```ts
try {
  await client.createTip({ creatorId: 'creator-123', amount: 0 });
} catch (error) {
  if (error instanceof Error && 'i18n' in error) {
    console.log(error.message);
    console.log(error.i18n);
  }
}
```

Current keys are `ERR_INVALID_AMOUNT`, `ERR_REQUIRED_FIELD`, `ERR_INVALID_INPUT`, `ERR_AUTHENTICATION_REQUIRED`, `ERR_FORBIDDEN`, `ERR_NOT_FOUND`, `ERR_RATE_LIMITED`, `ERR_TIMEOUT`, `ERR_NETWORK_ERROR`, `ERR_CREATE_TIP_FAILED`, `ERR_REQUEST_FAILED`, and `ERR_UNKNOWN`.
